# KCC IR Meet — 영문 IR 미팅용 치트 대시보드

외국인 투자자 미팅(Zoom·대면) 중 **30초 안에 입을 열게 해주는** 발화 보조 도구입니다.
정보 저장소가 아니라 **미팅 중에만 쓰는 화면**입니다. 빌드 없이 정적 파일만으로 동작하며 Vercel에 그대로 배포됩니다.

> 역할 분리: 내부 준비용(MBR·이사회·금지 리스트 포함)은 기존 `kcc_ir.html`(암호화)이고,
> 이 저장소는 **대외 발언 가능한 문장만** 담습니다. 그래서 암호화 대신 가벼운 패스코드만 둡니다.

## 네 가지 모드

| 모드 | 용도 | 조작 |
|---|---|---|
| **SPEAK** | 분기 탭(3Q 2026 · 2Q 2026 · 상시)별 스크립트. 종류: **Preview/Review**(분기 브리핑 7~10분) · **Segment**(사업부별 1분 코멘트 + 예상 질문) · **Topic**(밸류업·모멘티브·실리콘 비전 딥다이브) · **Intro**(회사 개요). 보기 방식 두 가지: **Full script**(전체 스크롤, 기본) / **Prompter**(한 화면 한 문단) | `←` `→` 문단 이동 · 문단 클릭 = 현재 위치 · `K` 한글 요지 · `T` 타이머 · Prompter에서 스와이프/탭/`Esc` 목차 |
| **ANSWER** | **검색창 + 카테고리(공통·건자재·도료·실리콘·배당·주주환원·자산활용·CAPEX·재무·거버넌스·IR·소재) + 하위 카테고리(실리콘: 실적·마진 / 시황·경쟁 / 모멘티브 재무 / 전략·Big Bets / 운영·통합) + 시기 태그 + ★ Today**로 거르는 한 줄 목록 → 카드: ① 고정 문장 ② Core answer 한 문장 ③ 근거 2~4문장 ④ 숫자 3개 ⑤ 통역용 국문 핵심 ⑥ 병기 용어 ⑦ 발언 경계선 | `/` 검색창 · `Enter` 첫 결과 열기 · `←` `→` 카드 이동 · `Esc` 목록 복귀 · 행의 ☆ = 오늘 쓸 카드 담기 · **With interpreter** 토글 시 국문이 먼저·크게 |
| **PHRASES** | **IR Core ★**(회사 무관 IR 영어 필수 표현 186개, 10개 덱 × 필수/권장/심화, 목록 + 플래시카드 한→영, 외운 카드 기기 저장) · 생존영어(상황별) · 쉬운 단어 사전 · 발음(강세) · 숫자 변환기(억·조 ↔ billion·trillion) · 흔한 실수 | 하위 탭 · 플래시카드: `Space` 뒤집기 · `←` `→` · `K` 외웠음 |
| **FACTS** | 미팅마다 흔들리지 않게 못 박는 **고정 문장** + 2Q 확정 수치 · 재무 · 환원 · 실리콘 KPI | 칩으로 점프 |

공통: 상단 **한글** 토글(모드별로 기억, SPEAK·PHRASES는 기본 숨김), **A− / A+** 글자 크기, **🌓** 다크 모드. 모두 기기(localStorage)에 저장됩니다.

검색은 **카테고리·시기 필터를 무시하고 전체 카드**를 훑습니다(제목, 태그, Core·근거 문장, 국문 핵심, 용어, 숫자 라벨). 제목에 맞은 카드가 먼저 오고, 한글 별칭(물산→Samsung C&T, 자사주→treasury, 유동화→monetisation 등)은 `assets/app.js`의 `ALIASES`에서 추가합니다. 띄어쓰기로 여러 단어를 넣으면 AND 조건입니다(예: `유동화 시점`, `실리콘 마진`).

**미팅 전 준비 루틴**: ANSWER에서 오늘 나올 질문 6~8개에 ☆를 눌러 **★ Today**에 담고, SPEAK에서 오늘 쓸 스크립트를 열어 둡니다. 미팅 중에는 ★ Today → 검색 순으로 찾습니다.

## 파일 구조 — 어디를 고치면 되나

```
index.html          화면 뼈대 (거의 손댈 일 없음)
assets/app.css      스타일 (kccirdashboard 네이비 팔레트)
assets/app.js       동작 (라우팅·프롬프터·변환기)
data/config.js      ★ 분기 라벨, 상태 문구, 패스코드
data/scripts.js     ★ SPEAK 스크립트 (분기마다 교체)
data/answers.js     ★ ANSWER 19개 카드 (수치·문장 갱신)
data/phrases.js     PHRASES (분기 무관, 유지)
data/study.js       IR Core 암기 덱 (회사 무관, 유지 — 표현 추가 시 여기)
data/facts.js       ★ FACTS 숫자표 (확정 분기로 교체)
```

### 누적 구조
- 스크립트마다 `quarter`("3Q 2026" / 상시는 "Evergreen")와 `kind`(Preview · Review · Topic · Intro)가 있어 SPEAK 상단 분기 탭으로 나뉩니다. 지난 분기 스크립트는 지우지 않아도 됩니다.
- Q&A 카드마다 `cat`(카테고리 id), `period`("3Q26" 등 시기 태그), `updated`(최종 수정일)가 있습니다. 시기가 2개 이상이면 ANSWER에 시기 필터 칩이 자동으로 생깁니다.
- 카테고리와 하위 카테고리(`subs`)는 `data/answers.js` 맨 위 `KCC_ANSWER_CATS`에서 추가·변경합니다. 카드의 `cat` / `sub`가 그 id를 가리킵니다.
- 카드 번호(`n`)는 파일 안에서 카드를 가리키는 고유 번호입니다. 목록에는 안 보이고 카드 제목 옆에 `#12`처럼만 표시됩니다.

### 분기 업데이트 순서 (예: 3Q 잠정공시 후)
1. `data/config.js` — `quarter`, `asOf` 수정, `status` 문구를 빈 문자열로(공시 전 경고 제거).
2. `data/scripts.js` — 새 분기 스크립트(Preview → Review)를 맨 위에 추가. `[ ]` 자리를 확정 수치로. 지난 분기는 그대로 두면 분기 탭에 남습니다.
3. `data/answers.js` — 스탠스가 같은 카드는 `numbers`·`support`·`updated`만 갱신하고 `period`를 새 분기로. 스탠스가 달라졌거나 새 관심사면 카드를 추가(번호 `n` 이어서).
4. `data/facts.js` — `direction` 블록 삭제 또는 갱신, `confirmed` 블록을 최신 확정 분기로.
5. 커밋·푸시하면 Vercel이 자동 배포.

데이터 파일은 전부 `window.KCC_xxx = [...]` 형태의 일반 JS이므로 메모장에서도 수정할 수 있습니다. 문장 안에 큰따옴표(`"`)를 쓰려면 `\"`로 쓰거나 ‘ ’ 를 사용하세요.

### 내용 규칙
- **대외 발언 가능한 문장만.** 내부 추정치, MBR·이사회 수치, 고객사명, 특정 기관과의 비공개 대화는 넣지 않습니다.
- 한 문장 = 한 메시지, 12단어 이내 목표. 나열은 First / Second / Third. 어휘는 비즈니스 영어 그대로 두되, **낭독 호흡**을 위해 문장만 짧게.
- 전달이 흔들렸던 단어는 PHRASES › Easy words에 대체어를 두었습니다(막혔을 때만 쓰는 보조).
- 카드의 `hold`(여기까지만)는 발언 경계선을 한 줄로만 — 금지 리스트가 아닙니다.

## 배포 (Vercel)
1. Vercel → Add New Project → 이 저장소 Import.
2. Framework Preset: **Other**, Build Command: 비움, Output Directory: 비움(루트). `vercel.json`이 `cleanUrls`와 `noindex` 헤더를 설정합니다.
3. Deploy. 이후에는 `main`(또는 연결한 브랜치)에 푸시할 때마다 자동 배포.

잠금은 기본 꺼져 있습니다. 필요하면 `data/config.js`의 `passcode`에 값을 넣으면 패스코드 화면이 생깁니다.
클라이언트 측 잠금이라 **억제 장치일 뿐 보안이 아닙니다** — 그래서 내부 자료는 이 저장소에 넣지 않습니다.

## 폰·태블릿에 설치
- 배포 URL을 Safari/Chrome으로 열고 **홈 화면에 추가** → 전체화면 앱처럼 실행(매니페스트 포함).
- 대면 미팅: 세로 모드, 하단 탭 4개, 큰 버튼. PC 두 번째 모니터: 가로 모드, SPEAK 글자 2.3rem(A+로 더 키움).
- 네트워크 없는 곳: 폰트만 시스템 폰트로 대체되고 기능은 동일하게 동작합니다.

## IR Core PDF (태블릿용 가로형)
PHRASES › IR Core 덱 + KCC 덱 2개(핵심 답변 문장·통역 용어)를 A4 가로로 뽑는 암기용 PDF. 왼쪽 한글(문제) / 오른쪽 영문(답) 배치라 오른쪽을 가리고 외웁니다. PDF 파일은 저장소에 넣지 않고(공개 저장소) 아래 명령으로 로컬에서 생성합니다. 
`data/study.js`를 고친 뒤 다시 만들려면:

```bash
node scripts/build-study-pdf.mjs <Pretendard otf 폴더>
```

폰트 폴더를 생략하면 시스템 한글 폰트로 만들어집니다.
